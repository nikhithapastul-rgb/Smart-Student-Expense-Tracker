
# 💰 Smart Student Expense Tracker

## 📌 Project Description
Smart Student Expense Tracker is a Python-based application designed to help students manage their daily income and expenses.

It provides a simple dashboard to record transactions, calculate total income, total expenses, and remaining balance.

## 🎯 Objectives
- Track daily income and expenses.
- Manage spending by category.
- Calculate total savings and balance.
- Store transaction details using CSV files.
- Display expense analysis using charts.

## ✨ Features
- Add income and expenses.
- Select transaction categories.
- Choose transaction dates.
- View recent transactions.
- Calculate total income and expenses automatically.
- Display remaining balance.
- Visualize expenses using bar charts.
- Save transaction data in a CSV file.

## ⚙️ Installation

1. Install Python 3.
2. Clone the repository:

```bash
git clone https://github.com/nikhithapastul-rgb/Smart-Student-Expense-Tracker.git
```

3. Open the project folder:

```bash
cd Smart-Student-Expense-Tracker
```

4. Install required libraries:

```bash
pip install -r requirements.txt
```

## ▶️ How to Run

Run the following command:

```bash
python -m streamlit run main.py
```

The application will open in your web browser.
